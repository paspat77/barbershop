# 简剪理发预约微信小程序 · 微信云开发（CloudBase）接入教程

恭喜您选择**微信官方云开发（CloudBase）**！
通过微信云开发，您**无需购买服务器、无需备案域名、无需配置 HTTPS 证书**，即可拥有微信官方托管的高可用云数据库，实现手机端客户与理发师跨设备、跨微信实时数据同步！

---

## 一、在「微信开发者工具」中 1 分钟开通云开发

1. 打开 **微信开发者工具**，打开本项目根目录下的 `wechat-miniprogram` 文件夹。
2. 在开发者工具顶部的工具栏中，找到并点击 **「云开发」** 图标按钮。
3. 按照弹窗指引：
   - 填写环境名称：例如 `barber-prod` 或 `barbershop`；
   - 套餐选择：选择 **基础配额（免费版/按量计费）**；
   - 点击确定，等待几秒钟环境初始化完成。
4. 开通后，在弹出的「云开发控制台」左上角，会看到您的 **环境 ID（如 `cloud1-xxxxxx`）**，点击复制该环境 ID。

---

## 二、配置环境 ID 到代码中

打开 `wechat-miniprogram/app.js`：
将刚刚复制的云环境 ID 填入第 12 行的 `CLOUD_ENV_ID` 中：

```javascript
// wechat-miniprogram/app.js
const CLOUD_ENV_ID = 'cloud1-xxxxxx'; // 替换为你的真实云开发环境ID
```

*(如果留空，微信也会自动默认关联当前开发者的第一个可用云环境)*

---

## 三、创建云数据库集合（只需 30 秒）

在微信开发者工具点击「云开发」-> 点击顶部的 **「数据库」** 选项卡：

点击左侧的 **「+」（添加集合）**，依次创建两个集合：

1. **`appointments`** （用于保存顾客的预约单、核销码与服务通知记录）
   - 权限设置：选择 **「所有用户可读，仅创建者可读写」** 或 **「自定义安全规则」**。

2. **`schedules`** （用于保存理发师设置的有空/没空排班档期）
   - 权限设置：选择 **「所有用户可读，仅管理员可读写」**（普通顾客可读取，理发师可写入）。

---

## 四、本地测试与多手机实时联动体验

1. 点击微信开发者工具顶部 **「编译」**。
2. 控制台 Console 会打印出：`云开发初始化成功`。
3. 点击 **「真机调试」** 或 **「预览」**：
   - 手机 A（顾客）：预约 007 主理人 14:00 档期，提交后界面上方立即弹出「微信服务通知」，同时写入云端 `appointments`。
   - 手机 B（理发师）：打开小程序切到「理发师排班」，即可实时看到 14:00 已被顾客锁定；
   - 007 在手机 B 上点击 15:00 设为「休息」，手机 A 上的 15:00 档期立刻变成灰色不可预约！

---

## 五、上传并发布小程序

1. 点击微信开发者工具右上角 **「上传」** 按钮（版本号填 `1.0.0`）。
2. 打开 [微信公众平台后台](https://mp.weixin.qq.com) -> 「版本管理」->「提交审核」。
3. 审核通过后点击「发布」，您的理发店专属预约小程序就正式面向全网微信用户上线了！
